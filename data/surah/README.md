# `data/surah/`

114 paired files: `001.json` … `114.json` and `001.min.json` … `114.min.json`, plus `index.json` and `index.min.json`.

Each file contains one Surah with its full inline ayah list under `ayahs` in the full edition or `a` in the minified edition. See the [dataset guide](../README.md) and [schema reference](../../docs/SCHEMA.md#surah--datasurahnnnjson).
