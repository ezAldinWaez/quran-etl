# `data/ayah/`

6,236 paired files: `<sura:03>_<aya:03>.json` and `<sura:03>_<aya:03>.min.json`, plus `index.json` and `index.min.json`.

Each file contains one Ayah. Full files use descriptive fields and a `parents` map; minified files use short fields and the `ps` parent map. The `_` filename separator replaces `:` for Windows compatibility while JSON keys retain forms such as `2:255`. See the [dataset guide](../README.md) and [schema reference](../../docs/SCHEMA.md#ayah--dataayahsura03_aya03json).
