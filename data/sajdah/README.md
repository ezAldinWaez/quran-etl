# `data/sajdah/`

15 paired files: `01.json` … `15.json` and `01.min.json` … `15.min.json`, plus paired indexes.

Each sajdah is a point referencing one ayah. The full edition embeds it under `ayah_data`; the minified edition uses `ad` and represents the type as `"o"` for obligatory or `"r"` for recommended.
